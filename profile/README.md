## 🛠️ What We Do

**Jolly Panda Unity Packages** is a collection of Unity development tools created by **Usef Farahmand** as part of the Jolly Panda ecosystem.

We build practical tools that help game developers automate repetitive tasks, optimize their assets, validate their projects, and improve their everyday development workflows.

Our goal is simple:

> **Spend less time on repetitive tasks. Spend more time building great games.**

### 🎵 Audio Import Optimizer

A Unity Editor tool designed to analyze audio import settings, apply configurable optimization profiles, and help developers maintain consistent audio configurations across their projects.

Planned features include:

* 🔍 Audio asset scanning and analysis
* ⚙️ Configurable optimization profiles
* 📱 Platform-specific import settings
* 🧪 Validation and optimization recommendations
* 👀 Dry-run previews before applying changes
* ↩️ Import settings snapshots and recovery
* 📊 Reports and batch processing

**Status:** 🛠️ In Development

### 🧰 More Tools Coming Soon

We aim to expand the collection with additional tools for Unity developers, including project validation, asset management, editor automation, and data workflows.

Each package will have its own repository, documentation, compatibility information, and installation instructions.
